<h1>Wazuh SOC Home Lab</h1>

<h2>📌Description</h2>
A security monitoring lab featuring Wazuh, Suricata, and Sysmon for centralized endpoint detection and network intrusion monitoring.
<br />


<h2>🏗️Lab Architecture</h2>

<b>The lab is built using Oracle VM VirtualBox and includes the following components:</b>

- <b>Wazuh Server: Runs the central Wazuh Manager, Indexer, and Dashboard. Collects and correlates logs from agents and Suricata</b> 
- <b>Windows Endpoint (Windows 11 Pro) and Ubuntu 22.04 :Runs the Wazuh Agent for system monitoring and log forwarding.</b>
- <b>Suricata IDS/IPS: Monitors network traffic, Sends IDS alerts to Wazuh.</b>


<h2>Environments Used </h2>

- <b>Windows 10</b> (21H2)
